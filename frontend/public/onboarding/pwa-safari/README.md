# Скриншоты установки PWA через Safari

Инструкция в приложении использует пять скриншотов в следующем порядке:

1. `photo_1_2026-08-19_20-00-33.jpg` — кнопка с тремя точками в правом нижнем углу Safari.
2. `photo_2_2026-08-19_20-00-33.jpg` — действие «Поделиться» в меню Safari.
3. `photo_3_2026-08-19_20-00-33.jpg` — кнопка «Показать больше» в меню «Поделиться».
4. `photo_4_2026-08-19_20-00-33.jpg` — действие «Добавить на экран “Домой”».
5. `photo_5_2026-08-19_20-00-33.jpg` — экран подтверждения с включённым параметром «Открыть как веб-приложение» и кнопкой «Добавить».

Эти имена файлов используются во frontend напрямую. При замене изображений сохраните имена и не добавляйте на скриншоты персональные данные, адреса серверов или другие закрытые сведения.
